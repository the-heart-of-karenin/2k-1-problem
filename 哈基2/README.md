## 审查后的继续重点

1. **根高度下降到η。** 旧十图的所有η均为k；本次补四图的η>k检验，812,570份非最高层查询无失败。样本结构仍有限，一般动态入口继续待证。
2. **账本的实际准备与有序服务。** B3精确刻画固定内部方向的自由立方体；四点λ=5见证有合法排程却不满足B3。后续应补准备与排程，不能把判据当成供给定理。
3. **用坏区域识别必须允许的外层绕行。** 八点122个紧邻合法边界全不连通，明确需要离开边界再返回。双向证书降为辅助框架：纯换证书不能释放真正blocked的边。
