本轮的实质内容是：

- 任意合法源态都有正循环流证书，无需先进入近层核或指定代表。
- 在准确的好流空间中，一份有限折线路径能转成保护全部原图割的真实单边翻转词；反向对应也成立。
- 坏流空间可由 bond 与至多 `k−1` 份允许外出身份的闭凸锥描述；这些锥的线性部分余维至少 `k+2`，但锥自身是满维的。
- 给出任意规模的障碍：统一流量比例不能覆盖全部合法源态；普通 nerve 的可缩交集条件也不能默认成立。

续轮进一步推导了任意坏锥交集的有向商图判定，以及同/异极性交叉的统一允许集包含。在低一层仍合法的交集上，索引复形可以按岸大小有限层流化。

但已层流的交集进入低一层好流空间后，仍可分成至少 `binomial(2r,r)` 份分量。这个任意规模的一般障碍说明：索引归约不能替代交集内部的拓扑。完整坏区消障仍缺。

选定的真实身份、实循环守恒、根最小割及坐标锥包含核验通过；它只检查已提出机制与构造，不枚举方向分量，不提供普遍量词。代码与输出都在本目录。
