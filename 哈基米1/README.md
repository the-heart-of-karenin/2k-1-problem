# 哈基米1：沿2k+1现有路线的核心攻击

2026-10-11。源资料位于同级 `../2k+1`，全部新增研究资料、程序、输出和检查点保存在本文件夹。旧资料保持原样。H1、H2、H3解析证明及主、独立核验均已完成；一般MAIN仍OPEN。

原问题 MAIN(k)：无自环、有独立物理身份的多重图满足 λ(G)≥2k+1 时，其全部 k 弧强定向能否通过每个前缀均合法的单边翻转连接。源项目将一般 MAIN 与一般路径服务标为 OPEN。

本轮接续结果148的实际端口账本，不先做正则化。重点是合法影子的供给、从任意实际源态进入共同层，以及多紧割保护的终止机制。

主要成果见 [H1完整证明](研究结果_H1_可变影子基与跨环境一步交接.md)。本轮去掉已支付服务中的固定基准端口要求：同一当前商态的合法k端口影子可交换；任意根星历史可以逐时选影子；核外单边翻转若两端核点义务差不超过q，就能用同一份真实内部准备共同保护全部割。

两个解析控制明确范围：有合法k影子也未必有容量影子，给任意k的五点例子及3k−3步真实退出；物理影子相差k/2份也不必支付k/2份额外单位，给q=1、共同额外义务为零的一步实际服务族。这些控制不被误称为MAIN反例或普遍入层证明。

主证书、[独立核验报告](variable_shadows_independent_audit.json)、[本轮检查点](研究检查点_2026-10-11_H1.json)保存准确输入、逐身份词、全部割核验、最大流核验及来源hash。有限核验包含3118份商签名、79440份基交换、67份常规实际词，另有七份退出词与四份大身份差控制；独立重算850374行字面完整割和640次根最大流。

第二项成果见 [H2完整证明](研究结果_H2_指定降根端口的任意源态入口.md)：R=k+1且指定商降根步合法时，任意实际源态最多翻n−1条核内边就能准备该端口，每个完整前缀合法；再翻端口到R=k。使用同一实际源态全部混合紧割的交集和真实有向路径，覆盖不同核trace的多守卫。准确升、降及返回均保留物理身份；访问近出层或近入层的商历史可从任意源态提升。

H2还给边界2k+3、根指出k+1却没有任何影子的任意k控制族；先翻一条核外边，再插入核内入口并降根，整份[h,准备,g]从任意实际源态出发，长度≤n+1。它没有把一般无影子状态一并报完成。

[H2独立核验](root_entry_H2_independent_audit.json)穷尽5500份合法内部态、8082份状态/指定步组合，核对2639份未支付入口、48份准确服务及3454份无影子退出；重算7271698行实际完整有向割，另检查7470次有向、253次无向根流。大控制包括30步核内路径、k=50与被紧割阻挡的最短捷径。

最新成果见 [H3完整证明](研究结果_H3_唯一饱和守卫与双单位接力.md)。不再要求指定商端口可翻，证明排斥同一零超额外出点的正超额守卫至多对应一个供给点；若该点未饱和，或其它供给能避开它，仍有安全单路径入口。剩余障碍准确压到“唯一饱和守卫截断内部供给”。任意k控制族确实没有单路径入口，但两个单位接力可安全准备，长度n−1；没有把它误报为MAIN或冻结纤维反例。

H3还证明：外部h能在商图中解锁g时，已准备g端点的任何扩张都可实际执行[h,g]。结合新入口得到不限核外结构的条件提升。正式核验穷尽10326份内部态，审计12858份入口和440份饱和门；补充核验保存1216份外部解锁词。见 [H3独立核验](unique_guard_H3_independent_audit.json)、[解锁对核验](unlock_pair_H3_independent_audit.json)和[H3检查点](研究检查点_2026-10-11_H3.json)。探索性大筛查与正式证书分开，随机数百万状态不冒充普遍证明。

阅读与推进记录见 [研究日志](研究日志_2026-10-11.md)。下一核心接口是一般唯一饱和门中的双单位接力及新紧割控制；其它无影子环境、更高根出度、根极值大于k、全局供给与终止仍未解决。
